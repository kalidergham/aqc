# 🎙️ بوت استنساخ الأصوات (Voice Cloning Bot)

بوت تليجرام مبني بـ `aiogram 3.x` و `aiohttp`، يستنسخ صوت المستخدم عبر **ElevenLabs**
ثم ينطق أي نص بصوته. كل الكود في ملف واحد: `bot.py`.

## ✨ المميزات
- إدارة الحالة عبر **FSM** (بانتظار الصوت ← بانتظار النص).
- طلبات **غير متزامنة** عبر `aiohttp` (لا تجميد للبوت).
- فصل تام بين **التدريب** (استنساخ الصوت) و**التوليد** (تحويل النص).
- حفظ `voice_id` في ذاكرة المستخدم حتى يغيّر صوته بأمر `/start`.
- إخراج الصوت بصيغة **OGG/Opus** المتوافقة مع بصمة تليجرام.
- معالجة شاملة للأخطاء + تعليقات عربية.

## 📦 التثبيت على Termux

```bash
# 1) تحديث الحزم
pkg update && pkg upgrade -y

# 2) تثبيت بايثون و ffmpeg (ffmpeg ضروري لتحويل الصوت إلى ogg)
pkg install python ffmpeg -y

# 3) تثبيت المكتبات
pip install aiogram aiohttp python-dotenv
# أو:  pip install -r requirements.txt
```

## ⚙️ الإعداد

```bash
# انسخ ملف المثال واملأ مفاتيحك
cp .env.example .env
nano .env   # ضع BOT_TOKEN و ELEVENLABS_API_KEY
```

## ▶️ التشغيل

```bash
python bot.py
```

## 🧭 طريقة الاستخدام
1. أرسل `/start`.
2. أرسل مقطعاً صوتياً واضحاً (≥ 30 ثانية).
3. انتظر رسالة "تم استنساخ صوتك".
4. أرسل أي نص ← يصلك مقطع صوتي بصوتك.
5. `/start` لاستنساخ صوت جديد، و `/cancel` للإلغاء.

## ⚠️ ملاحظات مهمة
- استنساخ الأصوات (Instant Voice Cloning) يتطلب اشتراكاً مدفوعاً في ElevenLabs (Starter فأعلى)؛ الباقة المجانية قد لا تسمح بإضافة أصوات مخصصة.
- لجودة استنساخ أفضل، أرسل تسجيلاً نظيفاً بدون ضجيج خلفي.
- استخدم البوت فقط على صوتك أو بإذن صريح من صاحب الصوت (التزام قانوني وأخلاقي).
